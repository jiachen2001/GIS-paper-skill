# GIS 与空间分析方法审查

本文件用于距离、缓冲区、可达性、空间连接、路网、空间权重、空间聚合、空间自相关及尺度问题的设计与审查。

## 1. 坐标参考系统与距离面积计算

- 明确原始 CRS、分析 CRS 与输出 CRS。
- 经纬度坐标不能在未论证的情况下直接用于普通欧氏距离、面积或缓冲区计算。
- 局地研究优先判断是否存在适合研究区的投影坐标系；跨较大区域时考虑大地测量距离或适当投影的变形。
- 检查坐标轴顺序、单位、EPSG 定义和转换是否一致。
- 对距离、面积高度敏感的结论，必要时比较不同合理 CRS 或 geodesic 计算结果。

## 2. 空间连接与空间包含关系

- 明确 `within`、`contains`、`intersects`、`touches` 等空间谓词与研究定义是否一致。
- 检查边界点如何处理，以及这种处理是否可能系统性影响某些区域。
- 检查一对多空间连接是否造成样本扩张、重复计数或隐含权重。
- 检查未匹配对象的数量与空间分布，不能只报告匹配成功率。
- 对实体匹配、地理编码或行政区归属，记录模糊匹配和人工修正规则。

## 3. 缓冲区与邻域定义

- 缓冲区半径必须有行为、制度、经验或敏感性分析依据。
- 判断圆形欧氏缓冲区是否符合真实可达过程；道路、步行、公共交通约束显著时考虑网络服务区或时间等时圈。
- 检查多个缓冲区重叠后 POI、人口或事件是否被重复计数；重复是否符合估计目标。
- 对边界附近研究对象检查研究区裁剪造成的 edge effect。

## 4. 距离、可达性与空间阻抗

- 距离类型应由研究机制决定：直线距离、网络距离、行程时间或广义出行成本代表不同含义。
- 不默认网络距离更科学；如果研究问题本身关注几何邻近或尺度很小，欧氏距离可能合理。
- 对可达性指标明确机会集合、阻抗函数、阈值、衰减参数、竞争效应和分母。
- 阈值型指标需检查阈值附近结果是否敏感。
- 重力型、2SFCA 或类似指标需明确参数来源与解释，避免只因文献常用而照搬。

## 5. 网络分析

检查以下环节：

- 路网来源、版本、获取日期与覆盖范围；
- 步行、骑行、驾车或公共交通模式是否匹配研究场景；
- 单双向、道路等级、速度、禁行、转向限制和时间条件；
- 拓扑断裂、悬挂边、孤立组件与不可达情况；
- 起终点 snapping 的容差与失败率；
- 多条路径共享边时的重复经过是否代表真实暴露、流量或权重；
- shortest path 是否真的对应研究中的“选择路径”，还是仅为技术代理；
- 路径失败记录是否被静默删除。

如果只能使用近似路网或简化阻抗，报告近似影响并抽样与更高质量基准比较。

## 6. 空间聚合与尺度

- 明确原始观测尺度、聚合尺度和最终推断尺度。
- 检查行政区、网格、街区或缓冲区聚合是否改变统计关系。
- 关注 MAUP：不同分区方式或不同尺度可能改变系数、相关和显著性。
- 对聚合后的群体关系避免直接外推到个体层面，警惕生态谬误。
- 必要时在多个合理尺度下进行敏感性分析。

## 7. 空间权重与空间自相关

- 明确权重矩阵的定义：邻接、距离、kNN、网络邻接或其他机制。
- 权重构造应与扩散、交互或邻近机制一致，而不是只因软件默认。
- 说明是否标准化以及标准化如何影响解释。
- 检查全局和局部空间自相关是否与研究目的相关。
- 如果回归残差存在明显空间依赖，评估普通独立误差假设是否失效。
- 空间模型的选择应由理论与诊断共同支持，不能以 Moran's I 显著就机械改用某一种空间模型。

## 8. 时空数据

- 对轨迹、暴露、事件和时变 POI，统一时区、日期粒度和时间窗口。
- 判断静态空间数据是否能代表研究时点。
- 检查同一位置多时点观测的重复结构和时间自相关。
- 对时空插值、窗口聚合或时间匹配明确可接受误差。

## 9. 审查输出

发现问题时说明：

1. 当前空间定义是什么；
2. 它隐含了什么现实机制；
3. 该机制是否与研究问题一致；
4. 可能引入何种测量误差、选择偏差或尺度偏差；
5. 最小可行修改是什么；
6. 是否需要敏感性分析，以及比较哪些设定。
