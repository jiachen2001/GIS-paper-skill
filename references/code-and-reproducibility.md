# 程序实现与可复现性

## 1. 方法—代码对应
将公式、伪代码和论文方法逐项映射到筛选、连接、循环、空间操作、去重、加权、聚合与输出。

## 2. GIS 代码高风险点
重点检查：
- CRS 与单位；
- 经纬度轴顺序；
- spatial join 谓词；
- 一对多连接；
- buffer 与 distance 的坐标体系；
- 路网 snapping 与不可达记录；
- dissolve / groupby / merge 后样本量变化；
- missing geometry、invalid geometry 与空结果。

## 3. 数量审计
关键步骤应记录输入量、输出量、匹配成功数、失败数、重复数、排除数与异常摘要。任何无法解释的数量变化都应先审查。

## 4. API 与外部服务
保存请求参数、时间、版本或服务端条件；记录限流、失败、重试与持续缺失。不得只保留成功结果而忽略失败模式。

## 5. 可复现环境
记录随机种子、软件与依赖版本、关键参数、数据版本和运行配置。原始数据不得被覆盖。

## 6. 近似与加速
若使用抽样、简化路网、近似最近邻、缓存结果或其他加速，说明其是否改变研究估计对象，并与基准方法做误差比较。
