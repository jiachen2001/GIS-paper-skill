# 数据质量、匹配与多源融合

## 1. 数据生成机制
记录数据由谁、为何、何时、以什么规则生成；说明版本、覆盖率、更新频率和缺失模式。

## 2. 多源融合
统一坐标系、时间窗口、统计口径、变量定义、计量单位和编码规则。不同来源的一致性只有在误差机制相对独立时才构成更强证据。

## 3. 匹配质量
报告实体匹配、地理编码、空间连接和时间匹配的成功率，并检查未匹配记录是否集中在特定区域、群体或时段。

## 4. 缺失、异常与重复
分别处理缺失、异常和重复，不把它们视为同一种“脏数据”。
- 缺失：判断是否可能与研究变量或位置相关。
- 异常：区分真实极端值与技术错误。
- 重复：区分真实频次、重复测量、路径重叠和技术性重复。

## 5. 样本流失
记录初始样本、各步骤删除或失败数量、最终有效样本，并比较流失前后的空间与属性分布。

## 6. API 与网络采集
记录失败状态、重试、限流、超时、空返回和持续缺失。重试不能悄悄改变抽样框或只保留更容易获取的对象。
