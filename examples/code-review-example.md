# 示例：GeoPandas 空间连接代码审查

## 用户问题
“这段 GeoPandas 代码可以直接把 POI 连接到街道并 groupby 吗？”

## Skill 应如何审查
1. 检查两张表的 CRS 是否一致，距离/缓冲区计算是否使用合适的投影坐标系。
2. 检查 spatial join 的谓词是否与研究定义一致。
3. 检查一条 POI 是否可能匹配多个空间单元，从而导致一对多扩张。
4. 在 join 前后报告样本数、唯一 ID 数、未匹配数与重复匹配数。
5. 检查 groupby 前是否已经发生重复计数，以及这种重复是否具有现实意义。
6. 检查边界点、invalid geometry、missing geometry 和空结果如何处理。
7. 若代码修改了样本形成过程，论文方法与样本流报告也必须同步更新。

## 关键原则
“代码运行成功”不等于“研究定义被正确实现”。任何无法解释的样本数量变化都应先被当作方法学问题审查。
