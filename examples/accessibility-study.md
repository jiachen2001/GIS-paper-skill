# 示例：城市设施可达性研究

## 用户问题
“我想研究居民到公共服务设施的可达性，直接用直线距离可以吗？”

## Skill 应如何审查
1. 明确目标构念：几何邻近、实际出行可达性，还是服务机会获得程度。
2. 明确出行方式与空间约束：步行、驾车、公共交通是否受道路、河流、围墙、行政边界影响。
3. 若研究机制是实际出行，可优先评估网络距离、时间成本或服务区；若研究只是近邻空间关系，直线距离可能合理。
4. 检查 CRS 与距离单位。
5. 若使用阈值或缓冲区，说明阈值依据并做尺度敏感性分析。
6. 结论中准确表述指标代表的可达性维度，不把单一距离自动解释为真实行为。

## 关键原则
不是“网络距离永远优于直线距离”，而是距离定义必须与研究机制一致。
